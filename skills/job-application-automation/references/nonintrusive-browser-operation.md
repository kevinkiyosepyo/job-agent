# Nonintrusive browser operation

For Kevin's job applications, default to background control in his normal Chrome profile. Do not switch to visible foreground cursor control or a native file picker merely because a background action has trouble; exhaust supported page/CDP methods first. If Kevin explicitly gives control of the computer, foreground interaction is allowed, but keep it limited to the application window.

Immediately halt all browser mutation when Kevin says to stop. On resume, inspect the live form rather than assuming prior actions landed.

## Autofill reconciliation

MyGreenhouse and ATS autofill may carry stale or incorrect disclosures. Before submit, reconcile education, work authorization, sponsorship, veteran status, disability status, gender, race/ethnicity, and the exact resume filename against the approved profile. Select a real rendered option; never leave an autocomplete filter string unbound.
